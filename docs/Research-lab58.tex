\section{Lab 5 - Experimental Modeling Framework}

\subsection{Overview}

This section describes the experimental setup for testing our hypothesis: XGBoost with preprocessed Google Trends features can predict BET volatility spikes better than traditional models.

\subsection{Problem Formulation}

\subsubsection{Mathematical Definition}

Given historical data up to day $t$, predict if day $t+1$ will have high volatility:

\begin{equation}
y_{t+1} = \begin{cases}
1 & \text{if } \sigma_{t+1}^2 > \text{75th percentile} \\
0 & \text{otherwise}
\end{cases}
\end{equation}

This is a \textbf{binary classification problem} where we want to predict volatility spikes one day ahead.

\subsubsection{Input Features}

Total 80 features in 3 groups:

\textbf{Group 1 - Google Trends (40 features):}
\begin{itemize}
    \item 20 Romanian search queries (e.g., "criză financiară", "bursă")
    \item Rate of change: ROC$(k) = (G_t - G_{t-k}) / G_{t-k}$
\end{itemize}

\textbf{Group 2 - Technical indicators (30 features):}
\begin{itemize}
    \item Lagged volatilities: $\sigma_{t-1}^2, \ldots, \sigma_{t-20}^2$
    \item Moving averages: MA(5), MA(10), MA(20), MA(50)
    \item RSI, momentum, volatility of volatility
\end{itemize}

\textbf{Group 3 - Market controls (10 features):}
\begin{itemize}
    \item EUR/RON exchange rate, VIX, day-of-week dummies
\end{itemize}

\subsection{Data Description}

\textbf{Source:} BET index daily data (2010-2024)

\textbf{Size:} 3,533 trading days after cleaning

\textbf{Splits:}

    \item Training: 2,236 days (2010-2019, 63\%)
    \item Validation: 702 days (2020-2022, 20\%)
    \item Test: 497 days (2023-2024, 14\%)
\end{itemize}

\textbf{Target distribution:}
\begin{itemize}
    \item High volatility (1): 25\% of days
    \item Low volatility (0): 75\% of days
\end{itemize}

\subsection{Preprocessing Pipeline}

\textbf{Problem:} Google Trends has missing values (60-80\% zeros) and noise

\textbf{Solution:} 3-step pipeline from Djorno et al. (2025):

\begin{enumerate}
    \item \textbf{Clustering:} Group correlated queries
    \begin{equation}
    d_{ij} = 1 - |\text{corr}(G_i, G_j)|
    \end{equation}
    
    \item \textbf{Smoothing:} Remove noise with splines
    \begin{equation}
    \hat{G} = \arg\min_g \left[\sum (G_t - g_t)^2 + \lambda \int (g'')^2 \right]
    \end{equation}
    
    \item \textbf{Detrending:} Remove long-term trends
    \begin{equation}
    G_t^* = \hat{G}_t - \hat{G}_{t-1}
    \end{equation}
\end{enumerate}

\subsection{XGBoost Model}

\subsubsection{Architecture}

XGBoost builds an ensemble of decision trees:
\begin{equation}
\hat{y} = \sum_{k=1}^{K} f_k(\mathbf{x})
\end{equation}

where each tree $f_k$ is added to minimize the loss function.

\subsubsection{Hyperparameters}

Grid search over:
\begin{itemize}
    \item Number of trees: $K \in \{50, 100, 200, 300\}$
    \item Learning rate: $\eta \in \{0.01, 0.05, 0.1\}$
    \item Max depth: $d \in \{3, 5, 7\}$
    \item Subsample ratio: $\rho \in \{0.7, 0.8, 1.0\}$
\end{itemize}

Total: $4 \times 3 \times 3 \times 3 = 108$ configurations tested

\subsection{Baseline Models}

To prove our approach works, we compare against:

    \item \textbf{GARCH(1,1):} Traditional econometric model
    \begin{equation}
    \sigma_t^2 = \omega + \alpha r_{t-1}^2 + \beta \sigma_{t-1}^2
    \end{equation}
    
    \item \textbf{Logistic Regression:} Simple linear baseline
    
    \item \textbf{Random Forest:} 200 trees, depth 10
    
    \item \textbf{LSTM:} Neural network with 2 layers (64, 32 units)
    
    \item \textbf{Naive:} Predict high volatility if yesterday was high
\end{enumerate}

\end{itemize}
